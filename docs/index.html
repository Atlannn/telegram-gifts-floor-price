Telegram gifts floor price API

Free JSON with the daily floor price of every Telegram NFT gift collection (Plush Pepe, Durov's Cap, Lol Pop and the rest). No key, no sign-up, CORS enabled. Data comes from fragment.com, collected once a day by GitHub Actions. Prices are in GRAM (the coin formerly called TON), with USD and EUR at that day's rate.

Endpoints

GET /api/v1/index.json                   list of collections and the latest date
GET /api/v1/latest.json                  today's floor of every collection
GET /api/v1/collections/<slug>.json     full daily history of one collection

Base URL: https://atlannn.github.io/telegram-gifts-floor-price

Try it: latest.json, plushpepe.json.

Example

curl https://atlannn.github.io/telegram-gifts-floor-price/api/v1/collections/plushpepe.json
fetch("https://atlannn.github.io/telegram-gifts-floor-price/api/v1/latest.json")
  .then(r => r.json())
  .then(d => console.log(d.floors.plushpepe.floor_usd));

Fields

  • floor_gram: cheapest lot, in GRAM. Can be an auction price.
  • floor_fixed_gram: cheapest fixed-price lot, or null.
  • floor_usd, floor_eur: floor_gram at that day's rate (null if no rate was stored).
  • lots_seen: lots counted on the first Fragment page (at most 60, not the total listed).
  • auctions_seen: how many of those lots are auctions.

A floor is an asking price, not a sale price, and fees are not included.
